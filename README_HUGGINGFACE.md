# 🎬 Movie Poster Face Swap

Swap faces from a couples photo onto a movie poster using AI!

## How to Use

1. Upload a **movie poster** with visible faces
2. Upload a **couples photo** with 2 faces
3. Click "Swap Faces" and wait for the magic! ✨

## Features

- 🤖 AI-powered face detection using InsightFace
- ✨ Face enhancement with GPEN models
- 🎭 Automatic face swapping
- 🆓 100% free to use

## Tips for Best Results

- ✅ Use high-resolution images (at least 512px)
- ✅ Ensure faces are clearly visible and well-lit
- ✅ Front-facing photos work best
- ⚡ First run may take 1-2 minutes (downloading AI models)

## Technology

This app uses:
- [face2face](https://github.com/SocAIty/face2face) - Face swapping SDK
- [InsightFace](https://github.com/deepinsight/insightface) - Face detection & analysis
- [GPEN](https://github.com/yangxy/GPEN) - Face enhancement
- [Gradio](https://gradio.app) - Web interface
